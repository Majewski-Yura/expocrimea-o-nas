# Страница «О компании» для expocrimea.com

- `o-nas.html` — вёрстка страницы (одним файлом, стили и скрипт внутри).
- `КОНТЕКСТ.md` — стиль сайта, факты о компании, структура страницы и что нужно от заказчика.
- `site-source/` — HTML и CSS главной страницы сайта для справки, логотип.
- `screenshots/` — скриншоты главной страницы.

Посмотреть локально:

```bash
python3 -m http.server 8765
```

и открыть http://localhost:8765/o-nas.html

Заглушки, которые нужно заменить: сотрудники и руководство (массив `TEAM` в конце файла и карточки «Руководство»), годы в «Истории», логотипы партнёров, реквизиты, ссылки на PDF, фото площадок.

`logos/` — цветные логотипы проектов из Figma-файла «Экспокрым — стилистика» (страница «Орг»). У «Чемпионата национальной кухни» и «Ефетовских чтений» логотипов в файле нет, в плитках пока название текстом.

# Страница «О компании» для expocrimea.com

- `index.html` — главная, `o-nas.html` — «О компании».
- `assets/site.css`, `assets/site.js` — общие стили и скрипт всех страниц.
- `tools/typograf.py` — расстановка неразрывных пробелов.
- `КОНТЕКСТ.md` — стиль сайта, факты о компании, структура страницы и что нужно от заказчика.
- `site-source/` — HTML и CSS главной страницы сайта для справки, логотип.
- `screenshots/` — скриншоты главной страницы.

Посмотреть локально:

```bash
python3 -m http.server 8765
```

и открыть http://localhost:8765/o-nas.html

Заглушки, которые нужно заменить: сотрудники и руководство (массив `TEAM` в конце файла и карточки «Руководство»), годы в «Истории», логотипы партнёров, реквизиты, ссылки на PDF, фото площадок.

`logos/` — цветные логотипы проектов из Figma-файла «Экспокрым — стилистика» (страница «Орг»). Логотип ЧНК — из файла «ЧНК-26» (версия 2, знак), «Ефетовских чтений» — знак из файла «Ефетовские чтения» (шапка ЕЧ).

`logos/partners/` — логотипы органов власти и партнёров из страниц «Оф поддержка» и «Оф партнеры» файла «Экспокрым — стилистика» (PNG 160 px).
